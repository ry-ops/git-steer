# Git-Steer Project

Git-Steer looks after a fleet of GitHub repositories and runs only on GitHub (ADR-008, `adr/ADR-008.yaml`): GitHub-native protection, self-healing repos, and a read-only fleet view. It is never run on a workstation, and nothing in it writes to more than one repo per run.

## Project Structure

- `adr/` - Architecture decisions; ADR-008 is current
- `src/github/client.ts` - Rate-limit-hardened GitHub API client (throttle/retry, ETag cache, concurrency caps)
- `src/state/manager.ts` - Reads/writes the `git-steer-state` repo
- `src/dashboard/` - Dashboard HTML, used by `scripts/ci-dashboard.mjs`
- `scripts/` - `ci-dashboard.mjs` (Layer 2 building block), `ci-changelog.mjs`
- `.github/workflows/` - `ci.yml`, `lockfiles.yml` (Layer 1 prototype), others

## Development

```bash
npm ci
npm run build    # Compile TypeScript
npm run lint     # ESLint
npm test         # Run tests (vitest)
```

Lockfiles are generated by the Lockfiles workflow on PRs; don't edit them by hand.
